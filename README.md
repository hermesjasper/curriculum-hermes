# Curriculum Hermes

Portfólio e currículo profissional de Hermes Winarski, organizados como uma linha do tempo reversa.

## Visualização local

Abra `index.html` diretamente no navegador. O projeto é estático e não exige instalação de dependências.

## Estrutura

- `index.html`: conteúdo e estrutura da página;
- `styles.css`: identidade visual e comportamento responsivo;
- `script.js`: menu, filtros e animações de entrada;
- `assets/`: imagens provisórias dos projetos.
